# Deutsch (phone)

Offline web app version of the Deutsch trainer. Same exercises, spaced repetition, reading, speaking, Spickzettel.
Progress lives on the device (localStorage). Claude help is optional and uses your own Anthropic key (Einstellungen).

Needs to be served over https (or localhost) once so the phone can install it; after that it runs offline.
Progress file format is the same as the laptop's progress.json (Einstellungen: save / load).
